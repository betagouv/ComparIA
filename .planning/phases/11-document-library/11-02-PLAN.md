<objective>
Expose the DocumentRegistry via two REST endpoints on the existing /tool-arena router:

- GET /tool-arena/documents — returns list[DocumentSummary] (id, title, description — no content)
- GET /tool-arena/documents/{doc_id} — returns DocumentDetail (id, title, description, content) or 404

Purpose: The frontend document picker needs a way to enumerate available documents and fetch their content. These endpoints bridge the in-memory DocumentRegistry (wave 1) to the HTTP layer.

Output: Two new endpoints wired to document_registry singleton in router.py, plus integration tests in test_router_documents.py.
</objective>
